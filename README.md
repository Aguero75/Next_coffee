# ☕ Next Coffee

**Coffee House | Home of the Best Brews.**

A modern, responsive coffee shop landing page built with Next.js — complete with a floating WhatsApp button so customers can place orders directly through chat.

🔗 **Live demo:** [next-coffee-lyart.vercel.app](https://next-coffee-lyart.vercel.app/)

---

## ✨ Features

- 🎨 Clean, modern landing page design for a coffee shop / cafe
- 💬 Floating WhatsApp icon for quick, frictionless order placement
- 📱 Fully responsive across mobile, tablet, and desktop
- ⚡ Built on the Next.js App Router for fast performance
- 🎯 Simple, easy-to-customize structure — swap in your own menu, branding, and copy

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/) — React framework (App Router)
- [React](https://react.dev/)
- CSS / PostCSS for styling
- [ESLint](https://eslint.org/) for code linting
- Deployed on [Vercel](https://vercel.com/)

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/Aguero75/Next_coffee.git
cd Next_coffee
npm install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.
